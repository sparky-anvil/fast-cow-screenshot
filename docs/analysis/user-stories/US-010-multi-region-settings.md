# US-010: Настройки режима «Несколько областей»

| Поле | Значение |
|---|---|
| Статус | Approved |
| Приоритет | Should |
| Оценка | S |
| Требования | REQ-002 (2.2, 2.27–2.31), REQ-001.4 |

## История

**Как** пользователь,
**я хочу** настроить горячую клавишу, клавиши оверлея, лимит областей и цвет заливки,
**чтобы** режим не конфликтовал с моими приложениями и подходил под мои задачи.

## Критерии приёмки

### AC-1: Значения по умолчанию
- **Given** первый запуск
- **When** пользователь открывает настройки
- **Then** запуск `Ctrl+Shift+4`, «Собрать» `Enter`/`NumPad Enter`, «Удалить последнюю» `Backspace`/`Ctrl+Z`, «Отмена» `Esc`, лимит 10, цвет `#808080`

### AC-2: Переназначение и сохранение
- **Given** пользователь изменил все параметры и сохранил
- **When** приложение перезапущено
- **Then** действуют новые значения

### AC-3: Конфликт клавиш оверлея
- **Given** пользователь назначает `Enter` и на «Собрать», и на «Отмена»
- **When** сохраняет настройки
- **Then** сохранение отклоняется с сообщением о конфликте

### AC-4: Конфликт глобальной клавиши
- **Given** пользователь назначает запуск режима на `Ctrl+Shift+3`
- **When** сохраняет
- **Then** показывается конфликт с режимом «Область»

### AC-5: Валидация лимита и цвета
- **Given** пользователь вводит лимит 0 / 51 / «abc» или цвет `#GGG`
- **When** сохраняет
- **Then** значение отклоняется с подсказкой о допустимом диапазоне (2–50, `#RRGGBB`)

### AC-6: Сброс
- **Given** параметры изменены
- **When** пользователь нажимает «Сбросить» в разделе
- **Then** восстановлены значения AC-1

## Граничные случаи

- Глобальная клавиша занята другим процессом — уведомление по REQ-001.3.
- Изменение лимита при открытом оверлее — действует со следующего запуска.

## Заметки / UI

- Цвет выбирается палитрой и полем HEX.
