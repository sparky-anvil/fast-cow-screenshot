# US-012: Рисование карандашом по снимку

| Поле | Значение |
|---|---|
| Статус | Draft |
| Приоритет | Should |
| Оценка | M |
| Требования | REQ-003 (3.15–3.22) |

## История

**Как** пользователь, отправляющий снимок коллеге,
**я хочу** обвести или подчеркнуть нужное место карандашом выбранного цвета и толщины,
**чтобы** сразу было видно, на что смотреть.

## Критерии приёмки

### AC-1: Рисование штриха
- **Given** редактор открыт, инструмент «Карандаш», цвет красный, толщина 4 px
- **When** пользователь ведёт мышь с зажатой левой кнопкой и отпускает её
- **Then** вдоль пути мыши — непрерывная красная линия толщиной 4 физических пикселя изображения со скруглёнными концами; линия видна во время рисования

### AC-2: Толщина не зависит от масштаба
- **Given** масштаб просмотра 50 %, толщина 8 px
- **When** пользователь рисует штрих и нажимает «Готово»
- **Then** на итоговом изображении толщина линии 8 px (на экране во время рисования — 4 px)

### AC-3: Выбор цвета и толщины
- **Given** открыта палитра
- **When** пользователь выбирает синий и 16 px
- **Then** следующие штрихи синие толщиной 16 px; ранее нарисованные не меняются

### AC-4: Запоминание выбора
- **Given** пользователь выбрал жёлтый и 2 px, закрыл редактор и перезапустил приложение
- **When** редактор открывается снова
- **Then** выбраны жёлтый и 2 px

### AC-5: Точка
- **Given** инструмент «Карандаш», толщина 8 px
- **When** пользователь кликает без движения мыши
- **Then** нарисован круг диаметром 8 px

### AC-6: Отсечение по границе
- **Given** снимок 800×600
- **When** штрих выходит за правый край изображения и за пределы окна
- **Then** размер изображения остаётся 800×600, часть штриха за границей не видна; штрих продолжается, пока кнопка зажата

### AC-7: Undo / Redo
- **Given** нарисовано 3 штриха
- **When** пользователь дважды нажимает `Ctrl+Z`, затем один раз `Ctrl+Y`
- **Then** на снимке штрихи 1 и 2; при отмене всех штрихов изображение совпадает с исходным пиксель в пиксель

### AC-8: Новое изменение очищает повтор
- **Given** штрих отменён `Ctrl+Z`
- **When** пользователь рисует новый штрих
- **Then** «Повторить» недоступно

## Граничные случаи

- Окно теряет фокус во время рисования — штрих завершается в последней известной точке.
- Очень быстрое движение мыши — без разрывов (точки соединяются отрезками).
- 100+ штрихов на снимке 3 × 4K — отрисовка в рамках REQ-003.N2, история ≥ 100 изменений.
- Белый карандаш на белом фоне — допустимо.

## Заметки / UI

- Палитра: красный `#FF0000`, жёлтый `#FFD800`, зелёный `#00C853`, синий `#2979FF`, чёрный `#000000`, белый `#FFFFFF`.
- Толщины: 2, 4, 8, 16 px; курсор «Карандаша» — круг размера текущей толщины с учётом масштаба.
