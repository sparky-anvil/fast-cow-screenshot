# US-009: Склейка нескольких областей в одно изображение

| Поле | Значение |
|---|---|
| Статус | Approved |
| Приоритет | Should |
| Оценка | M |
| Требования | REQ-002 (2.20–2.26), REQ-001.23–42 |

## История

**Как** пользователь, выделивший несколько областей,
**я хочу** получить одно изображение, где фрагменты расположены как на экране, но без пустого пространства между ними,
**чтобы** сразу вставить компактный снимок в мессенджер или документ.

## Критерии приёмки

### AC-1: Сжатие пустот
- **Given** регионы A = (0,0)–(100,50) и B = (500,300)–(700,400), цвет заливки `#808080`
- **When** пользователь нажимает `Enter`
- **Then** результат 300×150: A в (0,0), B в (100,50), остальные пиксели `#808080`

### AC-2: Регионы в строку разной высоты
- **Given** A = (0,0)–(100,100) и B = (300,20)–(400,60)
- **When** пользователь подтверждает
- **Then** результат 200×100: A в (0,0), B в (100,20); пиксели над и под B — цвет заливки

### AC-3: Сохранение порядка
- **Given** любые непересекающиеся регионы
- **When** выполняется склейка
- **Then** регион, целиком левее (выше) другого на экране, остаётся левее (выше) на результате; регионы не пересекаются и не масштабируются

### AC-4: Независимость от порядка выделения
- **Given** те же регионы, выделенные в разном порядке
- **When** выполняется склейка
- **Then** результаты побайтно совпадают

### AC-5: Один регион
- **Given** выделен один регион
- **When** пользователь подтверждает
- **Then** результат идентичен снимку режима «Область» с тем же прямоугольником

### AC-6: Общий конвейер
- **Given** склейка завершена
- **When** результат готов
- **Then** изображение в буфере обмена, PNG сохранён по шаблону REQ-001.28, показано уведомление, доступно «Сохранить как…»

### AC-7: Пользовательский цвет
- **Given** в настройках «Цвет заливки» = `#FFFFFF`
- **When** выполняется склейка регионов «по диагонали»
- **Then** все пустоты результата — ровно `#FFFFFF`

## Граничные случаи

- Регионы на мониторах с отрицательными координатами — результат корректен.
- Касающиеся регионы — вплотную, без зазора.
- 10 регионов на 3 × 4K — в буфере ≤ 500 мс (REQ-002.N3).
- Часть региона вне мониторов — `#808080` (REQ-002.12).

## Заметки / UI

- Номера и рамки регионов в результат не попадают.
