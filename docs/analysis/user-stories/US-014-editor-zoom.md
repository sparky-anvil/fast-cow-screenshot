# US-014: Масштаб и прокрутка в редакторе

| Поле | Значение |
|---|---|
| Статус | Draft |
| Приоритет | Should |
| Оценка | S |
| Требования | REQ-003 (3.7–3.11) |

## История

**Как** пользователь с несколькими 4K-мониторами,
**я хочу** видеть большой снимок целиком и при необходимости приближать нужное место,
**чтобы** точно рисовать и перемещать фрагменты на снимке любого размера.

## Критерии приёмки

### AC-1: Вписать в окно при открытии
- **Given** снимок 11520×2160, окно редактора на мониторе 3840×2160
- **When** редактор открывается
- **Then** снимок виден целиком, масштаб меньше 100 % и показан в процентах

### AC-2: Маленький снимок не увеличивается
- **Given** снимок 300×200
- **When** редактор открывается
- **Then** масштаб 100 %, снимок по центру холста

### AC-3: Ctrl + колесо
- **Given** редактор открыт
- **When** пользователь крутит колесо с зажатым `Ctrl`
- **Then** масштаб меняется в диапазоне 10–800 % относительно точки под курсором

### AC-4: Быстрые масштабы
- **Given** любой масштаб
- **When** пользователь нажимает `Ctrl+1` / `Ctrl+0`
- **Then** масштаб 100 % / вписать в окно

### AC-5: Масштаб не влияет на результат
- **Given** масштаб 37 %
- **When** пользователь нажимает «Готово»
- **Then** размер итогового изображения совпадает с размером снимка в физических пикселях

## Граничные случаи

- Окно перенесено на монитор с другим масштабом Windows — масштаб просмотра в процентах не меняется.
- Прокрутка: колесо — по вертикали, `Shift` + колесо — по горизонтали.

## Заметки / UI

- 100 % = один пиксель снимка на один физический пиксель монитора (REQ-003 §5).
