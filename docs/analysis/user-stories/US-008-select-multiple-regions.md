# US-008: Выделение нескольких областей на экране

| Поле | Значение |
|---|---|
| Статус | Approved |
| Приоритет | Should |
| Оценка | M |
| Требования | REQ-002 (2.1–2.19), REQ-001.5, REQ-001.13 |

## История

**Как** пользователь, которому нужно показать несколько фрагментов экрана,
**я хочу** по одной горячей клавише выделить несколько непересекающихся областей и подтвердить выбор,
**чтобы** получить один снимок только с нужными фрагментами без ручной склейки.

## Критерии приёмки

### AC-1: Запуск режима
- **Given** приложение запущено в трее, настройки по умолчанию
- **When** пользователь нажимает `Ctrl+Shift+4`
- **Then** за ≤ 250 мс на всех мониторах появляется оверлей с замороженным кадром, счётчиком «0 / 10» и подсказкой клавиш

### AC-2: Добавление нескольких регионов
- **Given** открыт оверлей
- **When** пользователь выделяет перетаскиванием три непересекающихся прямоугольника
- **Then** оверлей остаётся открытым, на нём видны три рамки с номерами 1, 2, 3, счётчик «3 / 10»

### AC-3: Пересечение отклоняется
- **Given** на оверлее есть регион 1
- **When** пользователь отпускает выделение, пересекающее регион 1 хотя бы одним пикселем
- **Then** регион не добавляется, показывается подсказка «Области не должны пересекаться», регион 1 не изменён

### AC-4: Касание допускается
- **Given** регион 1 = (0,0)–(100,100)
- **When** пользователь выделяет (100,0)–(200,100)
- **Then** регион добавляется

### AC-5: Лимит
- **Given** выделено 10 регионов при лимите 10
- **When** пользователь пытается начать новое выделение
- **Then** выделение не начинается, показывается подсказка о лимите; после удаления одного региона выделение снова доступно

### AC-6: Удаление последнего и произвольного региона
- **Given** выделены регионы 1, 2, 3
- **When** пользователь нажимает `Backspace` (или `Ctrl+Z`)
- **Then** удаляется регион 3
- **When** затем пользователь щёлкает правой кнопкой внутри региона 1
- **Then** регион 1 удаляется, оставшийся регион перенумерован как 1

### AC-7: Подтверждение
- **Given** выделен хотя бы один регион
- **When** пользователь нажимает `Enter`
- **Then** оверлей закрывается и запускается склейка (US-009)

### AC-8: Подтверждение без регионов
- **Given** регионов нет
- **When** пользователь нажимает `Enter`
- **Then** оверлей остаётся открытым, показывается «Выделите хотя бы одну область»

### AC-9: Отмена
- **Given** выделено любое число регионов
- **When** пользователь нажимает `Esc`
- **Then** оверлей закрывается; буфер обмена, файлы и последний снимок не изменены

## Граничные случаи

- Клик без перетаскивания (< 2×2 px) — игнорируется, оверлей не закрывается.
- Правый клик вне регионов — ничего не происходит.
- Регион через границу мониторов с разным масштабом — координаты в физических пикселях.
- Повторное нажатие любой горячей клавиши захвата при открытом оверлее — игнорируется.

## Заметки / UI

- Невыделенная часть затемнена, регионы — незатемнённые с рамкой и номером в углу.
- Пересекающееся выделение во время перетаскивания подсвечивается красной рамкой.
