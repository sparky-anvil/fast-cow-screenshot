# US-011: Включение редактора и завершение редактирования

| Поле | Значение |
|---|---|
| Статус | Draft |
| Приоритет | Should |
| Оценка | M |
| Требования | REQ-003 (3.1–3.14, 3.37–3.45), REQ-001.23–42 |

## История

**Как** пользователь, которому иногда нужно пометить что-то на снимке,
**я хочу** включить в настройках редактор, чтобы снимок открывался в нём перед копированием и сохранением,
**чтобы** в буфер и в файл попадал уже готовый отредактированный снимок, а при выключенном редакторе всё работало быстро, как раньше.

## Критерии приёмки

### AC-1: Редактор выключен — поведение не меняется
- **Given** флажок «Открывать снимок в редакторе» выключен (значение по умолчанию)
- **When** пользователь делает снимок любым режимом
- **Then** редактор не открывается; снимок в буфере, файл сохранён, показано уведомление (как в REQ-001 / REQ-002)

### AC-2: Редактор включён — снимок открывается в редакторе
- **Given** флажок включён, в буфере обмена текст «abc»
- **When** пользователь нажимает `Ctrl+Shift+1`
- **Then** окно редактора развёрнуто на мониторе под курсором, снимок вписан в окно; в буфере по-прежнему «abc», новых файлов в директории по умолчанию нет, уведомления об успехе нет

### AC-3: «Готово»
- **Given** редактор открыт, на снимке есть штрих
- **When** пользователь нажимает `Ctrl+Enter` (или `Ctrl+S`, или кнопку «Готово»)
- **Then** редактор закрыт; изображение со штрихом в буфере; файл `Screenshot_<время захвата>.png` сохранён; показано уведомление; изображение доступно в «Сохранить как…» из трея

### AC-4: «Готово» без изменений
- **Given** редактор открыт, изменений нет
- **When** пользователь нажимает «Готово»
- **Then** файл и содержимое буфера совпадают пиксель в пиксель со снимком, полученным при выключенном редакторе

### AC-5: «Копировать»
- **Given** редактор открыт
- **When** пользователь нажимает `Ctrl+C`
- **Then** текущее изображение в буфере, файл не создан, редактор остаётся открытым, показано уведомление «Скопировано в буфер обмена»

### AC-6: «Сохранить как…»
- **Given** редактор открыт
- **When** пользователь нажимает `Ctrl+Shift+S` и выбирает файл `C:\Temp\bug.png`
- **Then** файл сохранён, буфер не изменён, редактор открыт; при следующем «Сохранить как…» диалог открывается в `C:\Temp`

### AC-7: «Отмена» без изменений
- **Given** редактор открыт, изменений нет
- **When** пользователь нажимает `Esc`
- **Then** редактор закрыт без вопросов; буфер, файлы и последний снимок не изменены

### AC-8: «Отмена» с изменениями
- **Given** на снимке нарисован штрих, ни «Копировать», ни «Сохранить как…» после него не выполнялись
- **When** пользователь нажимает `Esc` или закрывает окно крестиком
- **Then** показан вопрос «Закрыть без сохранения? Изменения будут потеряны.»; «Вернуться» оставляет редактор открытым со штрихом; «Закрыть» закрывает его без результата

### AC-9: Горячая клавиша при открытом редакторе
- **Given** редактор открыт
- **When** пользователь нажимает `Ctrl+Shift+2`
- **Then** новый захват не выполняется, окно редактора выходит на передний план, показана подсказка «Завершите редактирование снимка»

### AC-10: Отменённый захват
- **Given** редактор включён
- **When** пользователь в режиме «Область» нажимает `Esc` на оверлее
- **Then** редактор не открывается

## Граничные случаи

- Автосохранение выключено (REQ-001.35) — «Готово» копирует только в буфер.
- Ошибка записи файла при «Готово» — REQ-001.31; изображение остаётся последним снимком.
- Флажок выключен при открытом редакторе — текущий редактор доработает, следующий снимок пойдёт без редактора.
- Пункт трея «Сохранить как…» при открытом редакторе сохраняет предыдущий последний снимок.
- Выход из приложения через трей при несохранённых изменениях — вопрос подтверждения (REQ-003.45).

## Заметки / UI

- Флажок — в общем разделе настроек рядом с «Включать указатель мыши в снимок».
- В строке состояния редактора: размер Ш×В в физических пикселях и масштаб в процентах.
