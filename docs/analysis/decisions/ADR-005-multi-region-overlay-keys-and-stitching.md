# ADR-005: Режим «Несколько областей»: локальные клавиши оверлея, склейка сжатием координат, палитра цвета в Compose

| Поле | Значение |
|---|---|
| Статус | Accepted |
| Дата | 2026-11-08 |
| Автор | Tech |
| Связанные | REQ-002, US-008, US-009, US-010, ADR-001, ADR-002, ADR-003, TDD-003 |

## Контекст

REQ-002 добавляет режим захвата «Несколько областей». Требуются технические решения:

1. Модель **локальных клавиш оверлея** (REQ-002.13, 16, 18, 28): клавиши без Ctrl/Alt (`Enter`, `Backspace`, `Esc`),
   отличие `NumPad Enter` от `Enter`, основное и дополнительное сочетание. Существующий `HotkeyBinding` (REQ-001.4)
   требует Ctrl или Alt и коды Windows для `RegisterHotKey` — для оверлея не подходит.
2. **Приоритет клавиш оверлея над глобальными** (допущение REQ-002 §6): `RegisterHotKey` перехватывает сочетание до
   того, как оно попадёт в окно оверлея.
3. **Алгоритм склейки** «сжатие пустот» (REQ-002.20–24) и место его реализации.
4. **Выбор цвета** «палитрой и полем HEX» (REQ-002.27, US-010): в Compose Material 1.x нет готового color picker.

## Рассмотренные варианты

1. Клавиши оверлея:
   - **A1** — новый тип `OverlayKey` (коды AWT `VK_*`, модификаторы необязательны, флаг `numpad`), строки в JSON.
   - **A2** — расширить `HotkeyBinding` (снять требование Ctrl/Alt) — ломает контракт REQ-001.4 и регистрацию.
2. Приоритет оверлея:
   - **B1** — на время открытого оверлея «Несколько областей» снимать все глобальные клавиши (`unregisterAll`) и
     регистрировать заново при закрытии.
   - **B2** — запретить в настройках клавиши оверлея, совпадающие с глобальными — противоречит допущению REQ-002 §6.
3. Склейка:
   - **C1** — чистая функция в `domain` (`StitchLayout.compute`): для каждой оси слить проекции регионов в
     непересекающиеся отрезки, новая координата = смещение отрезка + (x − начало отрезка); копирование пикселей —
     отдельный объект `RegionStitcher` в `capture`.
   - **C2** — «вырезать» пустые столбцы/строки из `BufferedImage` поэлементно — O(W·H) проверок, медленнее, сложнее
     тестировать.
4. Цвет:
   - **D1** — палитра из 8 фиксированных образцов (Compose `Box` + `clickable`) + поле HEX.
   - **D2** — Swing `JColorChooser` — модальный Swing-диалог поверх Compose-окна, другой внешний вид.
   - **D3** — сторонняя библиотека color picker — новая зависимость.

## Сравнение

| Критерий | A1 / B1 / C1 / D1 | Альтернативы |
|---|---|---|
| Соответствие REQ-002 | Полное | A2 ломает REQ-001.4; B2 противоречит §6; D2/D3 — да |
| Производительность | C1: O(n log n) по регионам + `System.arraycopy` построчно, ≤ 500 мс (N3) | C2 — O(W·H) |
| Сложность / тестируемость | Чистые функции с unit-тестами | Выше |
| Зависимости | Новых нет | D3 — новая |

## Решение

Выбраны **A1, B1, C1, D1**:

- `OverlayKey` (пакет `settings`): коды AWT `VK_*`; поддерживаются `A–Z`, `0–9`, `F1–F12`, `Enter`, `NumPad Enter`,
  `Backspace`, `Esc`, `Delete`, `Space`; модификаторы Ctrl/Alt/Shift необязательны; строковый формат
  `"Ctrl+Z"`, `"NumPad Enter"`, пустая строка — «не назначено» (только для дополнительного сочетания).
- На время оверлея «Несколько областей» глобальные клавиши снимаются (`HotkeyService.unregisterAll`) и
  восстанавливаются (`SettingsController.registerAll`) при его закрытии. Режим «Область» REQ-001 не меняется.
- Склейка: `domain.StitchLayout.compute` + `capture.RegionStitcher.stitch`.
- Цвет: палитра из 8 образцов + поле HEX `#RRGGBB` в окне настроек Compose.

## Последствия

- **Положительные:** нет новых зависимостей; алгоритм склейки полностью покрывается unit-тестами (REQ-002.N6);
  клавиши оверлея не конфликтуют с глобальными.
- **Отрицательные / риски:** пока открыт оверлей «Несколько областей», глобальные клавиши других режимов не
  работают (и так игнорируются по REQ-001.5). Если при закрытии оверлея другое приложение успело занять сочетание,
  оно не восстановится — пишется `WARN`, пользователь увидит проблему при следующем нажатии. Палитра ограничена
  8 цветами, остальные — вводом HEX.
