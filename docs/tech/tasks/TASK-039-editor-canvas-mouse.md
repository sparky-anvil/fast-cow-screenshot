## 1. Цель

Подключить к холсту окна редактора нажатие, движение и отпускание левой кнопки мыши, уход указателя с холста и потерю
фокуса окна; нарисовать на холсте рамку под указателем и рамку перетаскиваемого фрагмента (синяя / красная при
пересечении), круг карандаша; менять курсор мыши. Вся логика уже есть в `EditorController` (TASK-037) — здесь только
передача событий и отрисовка.

## 2. Контекст

`EditorController` (TASK-037) принимает события в px холста: `pointerDown(x, y)`, `pointerMove(x, y)`,
`pointerUp(x, y)`, `pointerExit()`, `focusLost()`. Он хранит то, что нужно нарисовать: `liveStroke` (уже рисуется
TASK-038), `drag: DragPreview?` (`index`, `position`, `intersects`; позиция кандидата уже учитывается при рисовании
фрагментов в TASK-038), `hoverFragment: Int?` (фрагмент под указателем при инструменте «Перемещение»),
`hoverPoint: StrokePoint?` (точка изображения под указателем), `state.tool`, `penWidth`, `isClosed`.

Окно (TASK-038, `ui/EditorWindow.kt`, `ui/EditorContent.kt`): `EditorCanvas` — `Canvas` с `onSizeChanged` и
обработчиком колеса; `drawDocument` рисует снимок/фрагменты, штрихи, полосы прокрутки. Счётчик `canvasTick` читается
только внутри блока рисования.

События указателя вызывают контроллер **напрямую** (не через `invokeLater`, conventions §9).

**Выдержки из требований (дословно):**

> **REQ-003.15** Инструмент «Карандаш» рисует штрих произвольной формы: от нажатия левой кнопки мыши до её отпускания. Штрих — непрерывная линия со скруглёнными концами и сглаживанием, без разрывов при быстром движении мыши.
>
> **REQ-003.21** Штрих отображается во время рисования, а не только после отпускания кнопки.
>
> **REQ-003.24** Инструментом «Перемещение» пользователь перетаскивает фрагмент левой кнопкой мыши. … При наведении на фрагмент курсор меняется на «перемещение», а фрагмент подсвечивается рамкой. Рамки и подсветка в итоговое изображение не попадают.
>
> **REQ-003.25** … Если во время перетаскивания фрагмент пересекается с другим, система подсвечивает это (например, красной рамкой). …
>
> **REQ-003 §6** Штрих начат внутри изображения, курсор ушёл за пределы окна или холста — штрих продолжается, пока кнопка зажата, и отсекается по границе изображения. Окно редактора потеряло фокус во время рисования … — текущий штрих завершается в последней известной точке.
>
> **US-012, заметка UI:** курсор «Карандаша» — круг размера текущей толщины с учётом масштаба.
>
> **REQ-003.N2** Штрих карандаша отображается с задержкой ≤ 50 мс от движения мыши, ≥ 30 кадров/с при снимке 3 × 4K и масштабе «вписать в окно».
>
> **REQ-003.N3** Перетаскивание фрагмента — ≥ 30 кадров/с при 10 фрагментах суммарно 3 × 4K. …

## 8. Алгоритм и логика

**Эталонный фрагмент** — обработчики (`@OptIn(ExperimentalComposeUiApi::class)` уже стоит на `EditorCanvas`):

```kotlin
.onPointerEvent(PointerEventType.Press) { e ->
    if (e.buttons.isPrimaryPressed) {
        val p = e.changes.first().position
        controller.pointerDown(p.x, p.y)
    }
}
.onPointerEvent(PointerEventType.Move) { e ->
    val p = e.changes.first().position
    controller.pointerMove(p.x, p.y)
}
.onPointerEvent(PointerEventType.Release) { e ->
    if (!e.buttons.isPrimaryPressed) {
        val p = e.changes.first().position
        controller.pointerUp(p.x, p.y)
    }
}
.onPointerEvent(PointerEventType.Exit) { controller.pointerExit() }
```

Импорты: `androidx.compose.ui.input.pointer.isPrimaryPressed`, `PointerEventType`, `onPointerEvent`.

**Курсор** (в `EditorContent`, вместо прямого вызова `EditorCanvas` внутри `Box` холста):

```kotlin
val icon by remember(controller) {
    derivedStateOf { canvasTick.value; chromeTick.value; cursorIconFor(controller) }
}
Box(Modifier.fillMaxSize().pointerHoverIcon(icon)) {
    EditorCanvas(controller, bitmap, canvasTick)
}
```

`derivedStateOf` пересчитывает значок на каждое изменение счётчиков, но перекомпоновка `Box` происходит только при
смене значка — `EditorCanvas` и его обработчики указателя не пересоздаются.

```
cursorIconFor(c):
    c.isClosed                     -> PointerIcon.Default
    c.drag != null                 -> MOVE_ICON
    c.state.tool == PENCIL         -> PointerIcon.Crosshair
    c.hoverFragment != null        -> MOVE_ICON
    иначе                          -> PointerIcon.Default
```

**`drawDocument`, шаг 4 — рамки** (только на экране, в итог не попадают — итог строит `EditorRenderer`):

```
frameWidth = 2.dp.toPx()
frame(src: PixelRect, pos: PixelPoint, color) =
    drawRect(color, Offset(ox + pos.x * z, oy + pos.y * z), Size(src.width * z, src.height * z), style = DrawStroke(frameWidth))
if (drag != null) frame(st.sources[drag.index], drag.position, if (drag.intersects) INTERSECT_RED else HOVER_BLUE)
else if (st.tool == MOVE) controller.hoverFragment?.let { i -> frame(st.sources[i], st.positions[i], HOVER_BLUE) }
```

**Шаг 5 — круг карандаша:**

```
p = controller.hoverPoint
if (!controller.isClosed && st.tool == PENCIL && p != null):
    center = Offset(ox + p.x * z, oy + p.y * z)
    r = max(controller.penWidth * z / 2f, 2f)
    drawCircle(Color.Black, radius = r + 1f, center = center, style = DrawStroke(1f))
    drawCircle(Color.White, radius = r, center = center, style = DrawStroke(1f))
```

**Пример:** масштаб 50 %, толщина 16 → радиус круга `16 × 0.5 / 2 = 4` px холста; штрих на итоге — 16 px.

## 9. Ошибки и граничные случаи

| # | Ситуация | Поведение |
|---|---|---|
| 1 | Нажата правая или средняя кнопка | игнорируется (`isPrimaryPressed == false`) |
| 2 | Отпущена правая кнопка при зажатой левой | игнорируется |
| 3 | Указатель ушёл за холст/окно с зажатой кнопкой | события `Move` продолжают приходить, штрих/перетаскивание продолжаются; `Exit` только скрывает круг/подсветку |
| 4 | Потеря фокуса окна во время жеста | `focusLost()` — как отпускание в последней точке |
| 5 | Открыт `JOptionPane` (окно теряет фокус) | `focusLost()` — жестов нет, ничего не меняется |

## 15. Ловушки и подсказки

- Если `pointerHoverIcon` поставить на сам `Canvas` и вычислять значок внутри `EditorCanvas`, каждое движение мыши
  пересоздаст обработчики `onPointerEvent` и жест может оборваться — поэтому значок вычисляется снаружи через
  `derivedStateOf`.
- `PointerIcon(java.awt.Cursor)` — функция Compose Desktop (`androidx.compose.ui.input.pointer.PointerIcon`).
- Событие `Release` приходит для любой кнопки; проверка `!e.buttons.isPrimaryPressed` отсекает отпускание правой
  кнопки при зажатой левой.
- Если в п. 4 штрих обрывается при выходе указателя за окно — не исправлять обходом: `Blocked` + CLR к Tech с шагами.
